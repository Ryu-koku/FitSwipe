# FitSwipe

オフライン優先の筋トレ記録アプリです。トレーニング記録は端末内に保存し、ルームごとに同意した場合だけ、完了した記録をメンバーへ自動共有します。

## Expo版（Android・iOS）

唯一のアプリ実装は `mobile/` にあります。Android・iOS・WebでExpo / React Nativeを共通利用します。

```sh
cd mobile
pnpm install --frozen-lockfile
pnpm typecheck
pnpm lint
pnpm test
pnpm start
```

ネイティブ実行は `mobile/` で `pnpm android`、macOSでは `pnpm ios`。Android・iOSのネイティブプロジェクトはExpo Prebuildで生成し、生成ファイルは手編集しません。
ルーム接続先は `EXPO_PUBLIC_ROOMS_URL` に設定します。既存のサーバーAPIをそのまま使います。未設定の場合は「準備中」と表示します。
保存はAsyncStorageです。以前のKotlin版の端末データは自動移行されません。Play版更新でアプリデータ自体は削除しませんが、Kotlin版の記録はExpo版に表示されません。必要な記録は移行前に別途保全してください。

USB実機開発は [docs/usb-phone-development.md](docs/usb-phone-development.md)、Play内部テスト配信は [docs/automatic-internal-release.md](docs/automatic-internal-release.md) を参照してください。

## 画面と操作

- ホームは白・青緑のクリーンな配色で、カレンダー・緑の炎のストリーク・小さな筋力グラフを表示します。レベルと累計日数の共通欄は表示しません。設定は標準的な上部ヘッダーの歯車から開きます。
- ホームは通常の文字サイズでは固定表示です。文字拡大や極端に小さい画面では、操作が欠けないようスクロールを許可します。「詳しく見る」で筋力グラフの詳細・種目選択を開けます。
- カレンダーは横スワイプに追従して月を切り替えます。継続週数は設定の週開始曜日に従い、今週が未達成でも先週までの連続記録を保持します。
- フッターは「ホーム・＋・ルーム」の3つです。
- 中央の＋を押すとプリセット選択・編集画面が開き、フッターが消えて同じ位置に再生ボタンが現れます。
- 前回選んだプリセットはアプリを閉じても記憶します。再生ボタンで開始し、進行中のトレーニングがある場合は再開します。
- 通常種目と左右別種目に対応し、重量・回数・セット数・休憩・種目順を編集できます。
- 種目の行をタップすると個別編集、長押しして移動すると行全体が指に追従して並べ替わります。画面端では自動スクロールし、読み上げ操作でも上下へ動かせます。
- トレーニングカードはスワイプ、または小さな完了・スキップボタンで進めます。左端に戻る、右端に表示中の種目を編集するボタンがあります。重量・回数は横並びの数字を上下になぞって調整し、値が切り替わるとはっきり振動します。前後の数字はタップ・長押しでも変更でき、中央の数字をタップすると直接入力できます。画像やカードの余白から過去の重量・回数グラフを開けます。
- トレーニングの進捗バーは種目単位で、全セットが完了した種目だけ増えます。終了時は短い確認のあと「終了して記録を見る」で完了済みの記録を保存します。
- 休憩カードはスワイプ操作で進めます。休憩終了は音と振動で知らせます。
- ルーム一覧はメンバーの頭文字アイコンとルーム名だけで、行全体をタップして開きます。作成完了時に参加用QRと招待の共有を表示します。
- 自動共有はルームごとの明示的な同意が必要です。同意した月の1日以降の完了記録について種目・重量・回数・日時を共有し、修正・削除も反映します。通信失敗時は端末の記録を保ち、次回のアプリ利用時に再送します。自動共有の保存期間は当月と過去11か月です。共有停止で自動共有分だけを取り下げ、以前の手動共有は管理画面から削除できます。
- ルームの比較は毎月1日〜末日・日本時間の完了セット数です。左右別種目は両側完了で1セット、同数は同順位、記録なしは0。全期間の記録から集計するため、詳細表示のページ数に左右されません。縦棒が下から上へ伸び、アイコンや棒をタップすると詳細を開きます。人数が多い場合は横にスクロールできます。
- 端末で「動きを減らす」を有効にしている場合、月送り・並べ替え・棒グラフの演出を抑えます。

## 共有サーバー

共有サーバーはCloudflare Workers + D1だけで動かします。起動・公開手順と共有のしくみは [rooms-server/cloudflare/README.md](rooms-server/cloudflare/README.md) を参照してください。接続先は `EXPO_PUBLIC_ROOMS_URL` 環境変数でビルド時に指定します。未設定のビルドではルームは準備中になります。

## データ管理アプリとの分離

FitSwipeでは体重・体脂肪率・身長の任意読み取りと個人同期に対応しています。より広い健康データの閲覧・グラフ化は、別リポジトリのHealth Connect Dashboardで行います。


## バックアップ・体組成

設定のJSONバックアップには個人記録・種目・プリセット・体組成・設定のみを含め、認証トークン・ルーム情報・同期用の内部情報は含めません。旧形式の完全なJSONバックアップも読み込めます。復元は値と参照先を検証してから、現在の記録を残して新しいIDで追加します。設定はバックアップ側を採用し、ログイン中は現在のアカウントへ同期します。同じバックアップの再取り込みは追加となります。

CSVは完了したトレーニングの実施セットを出力します。左右別の重量・回数、セット番号、同日の別セッション、開始・終了日時を保持します。従来の `date,exercise,weightKg,reps` 形式も取り込めます。JSONは未実施セットも含む保全用、CSVは実施記録の交換用です。

ログイン画面から端末だけでの利用と保管データの復元を選べます。ログアウト後も設定にアクセスでき、アカウント削除後に残した端末記録も閲覧できます。体重・体脂肪率・身長はGoogleログイン中の個人同期に含まれ、ルームへは共有しません。従来端末内だけにあった体組成も更新後に送信待ちへ移行します。ヘルスケアからの身長はcmのまま保存します。

復元とCSV取り込みは端末への保存成功後に反映します。保存失敗時は現在の記録と送信待ちを変更せず再試行できます。旧CSV取り込みの連続した0始まりのセット番号と、旧ヘルスケア読み込みで100倍になった身長は読み込み時に補正します。CSVの種目IDはファイル内の識別に使い、同名種目も別々に保持します。ヘルスケアの体脂肪率は割合から百分率へ変換し、取得元IDをログイン・バックアップ復元後も保持します。既存の取得元付き測定は再読み込みで値を更新できます。

設定の「アイコン・表示名を変更」からプロフィールを編集できます。写真を選んでプレビューし、「保存」で表示名と一緒に更新します。アイコンを削除すると頭文字表示に戻ります。ルーム一覧・メンバー一覧・ランキングにも反映されます。保存には通信が必要で、プロフィール未登録の場合はルーム用アカウントを作成します。リリース前に共有サーバーの `0005_profile_avatar.sql` の適用と更新が必要です。

Googleログイン時はGoogleのプロフィール画像を初期アイコンとして使います。設定から選んだ写真やアイコン削除は再ログインでも保持します。既存ユーザーはサーバー更新後の再ログインで反映されます。Google画像がない場合や読み込めない場合は頭文字表示になります。サーバーには `0007_google_profile_picture.sql` までの未適用マイグレーションを順に適用してください。

Googleで新規ログインした場合、ルームの初期表示名もGoogleの名前になります。認証済みの名前を優先し、取得できない場合はGoogleログインSDKの名前、それもない場合は「トレーニー」を使用します。長い名前は32文字の入力上限に収めます。設定で変更済みの名前は再ログイン時に上書きしません。

## ストア提出・安全管理

[Google Play提出準備](docs/play-review-readiness.md) に、公開ページ、健康データの申告案、審査手順、通報・削除受付の運用をまとめています。ルーム利用前に規約への明示同意を保存し、投稿・プロフィールの通報と相互ブロックに対応します。公開前に共有サーバーの `0008_review_safety.sql` まで適用し、Workerを更新してください。

## プレミアム

プレミアムは月額300円（購入時はストア表示価格をご確認ください）の自動更新サブスクリプションです。

| 項目 | 無料 | プレミアム |
|---|---|---|
| プリセット | 3つ | 無制限 |
| 自作種目（アーカイブを除く・更新後に作成したもの） | 3つ | 無制限 |
| 自分が作成者のルーム | 2つ | 無制限 |

参加ルームは従来どおり合計30個までで、グラフに制限はありません。上限超過・解約後もデータは消えず、編集・利用・削除できます。制限するのは新規追加のみで、バックアップ復元・CSV取り込み・クラウド同期は上限を超えても取り込めます。

ビルド時に `EXPO_PUBLIC_REVENUECAT_ANDROID_KEY` / `EXPO_PUBLIC_REVENUECAT_IOS_KEY` を設定し、RevenueCatの `premium` entitlementと月額パッケージを用意します。未設定・Web・開発用パッケージでは購入は準備中です。開発時は `EXPO_PUBLIC_PREMIUM_OVERRIDE=1` で端末のプレミアム表示・上限解除を確認できます（サーバーの判定には影響しません）。サーバーには `REVENUECAT_SECRET_KEY` を設定します。購入にはネイティブモジュールを含むストア版ビルドが必要です。
