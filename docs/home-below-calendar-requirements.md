## 目的

ホームで、自分のトレーニング記録の変化と達成を確認できるようにする。
カレンダーは継続状況と日別記録、カレンダー下は種目ごとの変化を担う。
数値を押した先では、その根拠となる実際の重量・回数を確認できる。

## 決定の記録

- 第1稿：推移グラフと成長ランキングの両方を選べるようにする。推移では種目を選ぶ。記録不足時には理由と次の操作を示す。
- 第2稿Q1：推移の指標は推定最大重量・最大重量・最多回数に絞る。
- 第2稿Q2：詳細画面では、グラフに続いて自己ベストを先に見せる。
- 第2稿Q3：ランキングは推定最大重量の伸び率に加え、自己ベスト更新日数も選べるようにする。

## ホームの表示

カレンダー下に「推移／ランキング」の切替を置く。両方を縦に常時並べる構成にはしない。
初回は推移を表示する。期間は直近90日。以後は最後に選んだ表示・種目・指標を保持する。
カレンダーで表示している月に合わせて集計期間を変更する機能は、今回の要件には含めない。

### 推移

種目と指標を選択できる。左右別に記録する種目では、左・右を選択できる。

| 指標 | グラフに表示する情報 | 意味 |
| --- | --- | --- |
| 推定最大重量 | 日ごとの最大推定値 | 重量と回数から推定する、1回持ち上げられる最大重量 |
| 最大重量 | 日ごとの最大記録重量 | 実際に記録した重量の変化 |
| 最多回数 | 日ごとの最多記録回数 | 実際に記録した回数の変化 |

推定最大重量は実測値と区別して表示する。現行の対象条件は、重量あり・1〜10回の完了記録。
重量なしの種目では最多回数を表示し、推定最大重量の対象外である理由を示す。
最多回数を異なる重量で比較する場合もあるため、回数の増加だけで筋力向上とは断定しない。

セット数・総負荷量は今回の指標に追加しない。

### ランキング

ランキング内で次の2種類を切り替えられる。どちらも自分の種目間の比較で、他人との順位ではない。

| 種類 | 比較の定義 | 対象・表示 |
| --- | --- | --- |
| 筋力の伸び率 | 90日内の最初と最後の推定最大重量を比較する変化率 | 比較できる記録が2日以上ある種目。上位5種目。減少はマイナス表示。重量なし種目は対象外 |
| 自己ベスト更新日数 | 過去最高を超えた日を直近90日内で数える | 重量ありは推定最大重量、重量なしは最多回数。上位5種目 |

伸び率は `(最後の推定値 − 最初の推定値) ÷ 最初の推定値 × 100`。
自己ベスト更新日数は、初回記録・同値を更新に含めない。同じ日に複数回更新しても1日と数える。
「過去最高」の判定には90日より前の記録も必要であり、90日内だけの最高値更新とは区別する。
左右別種目は左右を区別して扱う。

伸び率は記録開始直後の種目が上位になりやすく、更新日数は実施頻度の高い種目が上位になりやすい。どちらも筋肉が増えた量を表すものとは扱わない。

## 押したときの動き

| 押す場所 | 表示するもの |
| --- | --- |
| 推移／ランキングの切替 | 同じホーム領域内で表示を切替 |
| 推移の種目選択 | 表示する種目を選ぶための一覧 |
| 推移の指標選択 | 推定最大重量・最大重量・最多回数の選択肢 |
| 左／右 | 選んだ側の推移 |
| ランキングの種類 | 伸び率／自己ベスト更新日数の切替 |
| 推移の「詳しく見る」 | 選んだ種目の詳細画面 |
| ランキングの種目行 | その種目の同じ詳細画面 |
| 詳細の自己ベスト | その記録を達成した日のトレーニング記録 |
| 詳細の履歴の日付 | その日の全セットの重量・回数 |
| 記録不足時の「トレーニングへ」 | 既存のトレーニング準備画面 |

## 種目詳細画面

表示順は、90日間の推移グラフ → 全期間の自己ベスト → 履歴への導線。
自己ベストは最大重量・最多回数を示し、それぞれ達成日と実際の重量・回数を確認できるようにする。
推定値と実際の記録は混同させない。
履歴から元の全セットを閲覧でき、ホームへ戻れる。

直近と前回を並べる専用比較表示は今回追加しない。記録中の既存の前回表示とは別の判断である。

## 記録不足時

領域を無言で隠すことはせず、表示できない理由と次の操作を示す。

- 記録なし：まだ記録がないことと、既存の準備画面への導線を表示。
- 推移が1日分：1点を表示。比較には次の記録が必要であることを伝える。
- 伸び率を計算できる種目なし：記録2日以上が必要であることを伝える。
- 推定最大重量の対象外：重量あり・1〜10回という対象条件を説明し、重量なし種目は最多回数で確認できるようにする。
- 自己ベスト未更新：初回や同値は更新として数えないことを明示し、記録がない状態と混同させない。

## 要件を満たしたと判断する条件

1. ホームで推移とランキングを切り替えられ、推移の種目・指標を変更できる。
2. 選択を保持し、再表示時に同じ情報を確認できる。
3. ランキングを伸び率と自己ベスト更新日数で切り替えられる。
4. どちらの表示からでも種目詳細へ進み、グラフの後に自己ベストを確認できる。
5. 自己ベスト・履歴から実際の全セットにたどり着ける。
6. 記録なし・1日分・対象外・未更新を区別して説明できる。
7. 左右別記録、実測と推定、90日間の推移と全期間の自己ベストを混同しない。
