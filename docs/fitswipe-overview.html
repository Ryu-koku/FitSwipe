Offline-first workout log

FitSwipeの画面構成と、できること。

FitSwipeは、筋トレの準備から実施、記録の振り返り、友だちとの共有までをひとつにつなぐAndroidアプリです。普段の記録は端末内に保存し、共有を選んだ記録だけをルームに投稿します。

01 / Overview

まずはこの流れで使います

起動後はホームが入口です。下部のドックは、ホーム・トレーニング準備・ルームを行き来するための共通ナビゲーションです。準備中は中央の「＋」が同じ位置の再生ボタンに変わります。

ホームカレンダー・設定
→
準備プリセットを選ぶ
→
トレーニングスワイプで進行
→
完了集計・共有
再開にも対応。 途中でアプリを閉じても進行中セッションを保持し、ホームから続きの種目を再開できます。
02 / Screens

画面一覧

入口

ホーム / カレンダー

過去の完了セッションをカレンダーで確認する画面です。右上の丸い歯車から設定へ移動できます。

  • 進行中のトレーニングがあれば「再開」または「終了」
  • 中央の「＋」からトレーニング準備へ
  • 完了した日の記録を確認
準備

トレーニング準備

作成済みのプリセットを選び、種目・セット数・順番・休憩を開始前に整えます。

  • プリセットの選択・追加・編集・削除
  • 種目の追加
  • 選択した内容を記憶して次回も利用
実施

トレーニング中

種目ごとのカードを操作してセットを記録します。画面はスリープせず、休憩タイマーも表示されます。

  • 重量 × 回数を入力
  • 左右別種目は左・右を個別に完了
  • カードのスワイプで次セット、またはスキップ
  • 休憩終了を音と振動で通知
振り返り

完了 / 記録

完了画面では種目数・セット数・所要時間を確認できます。記録画面ではプリセットごとの重量 × 完了セット数の推移を見られます。

  • ホームへ戻る
  • 完了記録をルームへ共有
  • プリセットを切り替えて推移を比較
設定

設定 / Preferences

アプリ全体の基本設定と、トレーニング素材を管理します。

  • 週の開始曜日（日曜 / 月曜）
  • 基本の重量増減幅、共通のセット間休憩
  • 種目名、種目別の重量刻み、休憩、左右の開始順
  • プリセットの追加・編集・削除
FitSwipe 設定
共通UI

下部ドック

「ホーム」「＋ / 再生」「ルーム」の3つを常に同じ位置に配置。準備画面ではフッターが消え、中央ボタンが再生に変わるため、片手で開始しやすい構成です。

03 / Workout

トレーニング中にできること

通常種目

各セットに重量と回数を入力し、完了操作で進捗へ反映します。

左右別種目

左右の重量・回数を別々に記録できます。右から / 左からの開始順、左右切り替え時の休憩も種目ごとに設定できます。

種目の順番

実施中の種目順画面から、まだ始めていない種目をドラッグして並べ替え、順番を適用できます。

休憩タイマー

セット間休憩と、必要に応じた左右切り替え休憩をカウントダウン。カードをスライドして早く終了することもできます。

04 / Rooms

ルームで記録を共有

招待制のルームに友だちを参加させ、共有したトレーニングだけをメンバーに見せられます。接続先が設定されていないビルドでは、ルームは「準備中」と表示されます。

初回

アカウントを作る

表示名を登録して、この端末専用の共有アカウントを作成します。

参加

ルームを作る / 入る

ルーム名で新規作成するか、招待コードまたは fitswipe://room?code=... のリンクから参加します。

投稿

完了記録を選んで共有

完了画面またはルーム内の「記録を共有」から、投稿するトレーニングを選択します。

安全性

端末記録と共有記録を分離

サーバーへ送るのは選択した記録のスナップショットだけです。通信失敗時は送信待ちに残し、ルーム表示・更新時に再送します。

05 / Data

データの扱い

端末内通常の種目・セッション・セット記録を保存
共有時だけ投稿した記録をルームのメンバーへ表示
別アプリHealth Connectの閲覧・グラフ化は対象外
