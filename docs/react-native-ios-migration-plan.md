# React Native移植

## 対象

既存Kotlin版（`app/`）の機能・画面・操作を、既存Expo／React Native版（`mobile/`）へ移す。Android・iOSで共通実装を使う。

- カレンダー、当日の記録、実績と表示項目の選択
- プリセット・種目の追加／編集／削除／並べ替え
- スワイプカード、左右別の進行、前回記録、戻る・スキップ・再開
- セット間休憩、種目別設定、音・振動による休憩終了通知
- テーマ、週開始曜日、重量の刻み幅、記録グラフ
- 既存ルームAPIでの共有、招待リンク、再送、退出・削除

## 対象外

新機能、デザイン刷新、SQLite等への保存方式変更、Kotlinデータの移行追加、サーバー仕様変更、ストアへのビルド提出・公開は行わない。保存は既存のAsyncStorageを継続する。

## 確認

`mobile/` で `pnpm typecheck`、`pnpm lint`、`pnpm test` を実行する。両OSのバンドル生成に加え、端末での画面・スワイプ・通知を確認する。

OS依存処理はExpoの通知・触覚・消灯防止に置き換える。通知はOSの許可・消音設定等に従う。iOSのネイティブビルドと実機確認にはmacOS／iPhoneまたはEASのビルド環境が必要。

### 実装後の確認（2026-10-26）

- 型チェック・lint：成功。
- 記録処理・送信待ち・既存Python APIとの接続テスト：25件成功。
- Expo Doctor：20/20チェック成功。
- Android・iOS向けのJavaScript／Hermesバンドル生成：成功。
- Androidのネイティブビルド：必要なNDK `27.1.12297006` がなく、SDKの配置先が書き込み不可のため停止。既存の生成済みディレクトリを変更せず、一時コピーで確認した。
- EASでAndroid APK・iOS Simulator向けのネイティブビルド確認を開始。コミット時点では完了未確認。ストアへの提出・公開は行っていない。
- ネイティブアプリの起動・タッチ操作・休憩通知の端末確認は未実施。
- `react-dom@19.3.1` と `react@19.3.0` の既存peer警告は今回の移植対象外とし、バージョンを変更していない。
