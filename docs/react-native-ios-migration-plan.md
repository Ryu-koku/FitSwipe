# Expo共通版への移行記録

## 移行結果

Android・iOS共通の唯一のアプリ実装を `mobile/` のExpo / React Native版に統一しました。Androidアプリの生成、USB実機開発、Play内部テスト配信もExpoプロジェクトを使用します。

- カレンダー、当日の記録、実績と表示項目の選択
- プリセット・種目の追加／編集／削除／並べ替え
- スワイプカード、左右別の進行、前回記録、戻る・スキップ・再開
- セット間休憩、種目別設定、音・振動による休憩終了通知
- テーマ、週開始曜日、重量の刻み幅、記録グラフ
- Googleログイン必須、クラウド同期、ルーム共有・招待・再送・退出・削除
- Android / iOSのネイティブビルドはExpo Prebuildで生成
- USB開発版はPlay版・従来の開発版と異なるアプリIDを使用
- Play内部テストは既存のパッケージ名・署名鍵を維持してExpo生成AABを配信

## 引き継ぎ上の注意

保存はAsyncStorageです。旧Android版のRoomデータ・設定をExpo版へ変換する処理は含めていません。Play版を更新してもAndroidアプリのデータ領域は消去されませんが、旧データはExpo版には表示されません。必要な記録を事前に保全してください。

## 確認

`mobile/` で `pnpm typecheck`、`pnpm lint`、`pnpm test` を実行します。両OSのバンドル生成に加え、端末での画面・スワイプ・通知を確認します。

OS依存処理はExpoの通知・触覚・消灯防止に置き換える。通知はOSの許可・消音設定等に従う。iOSのネイティブビルドと実機確認にはmacOS／iPhoneまたはEASのビルド環境が必要。
