# ホーム下部：実装と検証

確認日：2026-11-09
要件：[ホームの機能要件](home-below-calendar-requirements.md)

## 実装

- ホームで推移／ランキングを切替。種目検索、3指標、左右選択を追加。
- ランキングで伸び率／自己ベスト更新日数を切替。
- 両方の入口から同じ種目詳細へ移動。グラフの後に全期間の自己ベストを表示し、自己ベストや履歴から日別の全セットを開く。
- 表示・種目・指標・左右・ランキングの選択は既存の端末内保存に含める。古い保存データでは安全な初期値を使用する。この表示設定の端末間同期は追加していない。
- 集計は新しい `mobile/src/home-progress.ts` に分離。90日より前の記録も自己ベスト判定に使う。初日の記録は基準として扱い、同日の複数更新は1日として数える。
- 重量なしの記録は最多回数へ切替。記録不足・対象外・未更新の説明を表示する。
