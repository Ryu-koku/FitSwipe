回答原本：`akapen/home-record-overflow-02.html.answer.txt`。

## 変更

- 月全体と配置順を維持。日付行44→36px。5週で40px、6週で48px削減。
- ヘッダー・下部操作を除いた実際の領域と、表示中カレンダーの高さを測定して記録へ配分。
- 種目見出し、指標、最新値、1点時の補足の実測高を差し引き、グラフを100〜220pxに調整。
- SVGの座標を実際の幅・高さで再計算。軸ラベル11pxを維持し、低いグラフでは目盛りを減らす。
- 最低高やランキング全行を確保できない場合のみ縦スクロール。カード内部で切り捨てない。
- 詳細画面のグラフ寸法・集計内容は維持。
